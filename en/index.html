Automation · Python

Papotech Editor

Podcast editing automation with Python

A command-line tool that takes the recordings from two microphones and returns synced audio with long pauses shortened, a transcript and a list of spots to review. It came out of my own editing routine for the Papotech podcast.

  • Sync based on detecting hand claps (RMS energy and peak detection)
  • A single cut map applied to both microphones
  • Whisper transcription and TXT, SRT and CSV reports
  • Python
  • FFmpeg
  • Pydub
  • NumPy · SciPy
  • Whisper

An indie game built from many connected systems

About me

I learn by building.

I study Software Engineering (on campus) and Digital Games (online) at UniCesumar in Brazil. I started programming at around 15, making games in GameMaker Studio 2, and I've been turning what I learn into shipped projects ever since.

Today I work across web development, Python automation and games: I built the ManiProtein landing page, a tool that automates podcast editing and the public alpha of Ecos do Olimpo, which evolved with feedback from players. I also create content as FZF Dev (formerly FZF Productions): devlogs, tutorials and game jams.

Hackathons taught me how to work in a team on a tight deadline: validate an idea, split the work and pitch the solution to a panel of judges. Now I'm looking for a software development internship, ideally in front-end, where I can learn from a team and contribute to real products.
